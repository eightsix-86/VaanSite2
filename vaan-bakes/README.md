# Vaan Bakes

Welcome to the Vaan Bakes project! This is a delightful bakery website that showcases our delicious products and provides an interactive experience for our customers.

## Project Structure

The project is organized as follows:

```
vaan-bakes
├── index.html          # Main HTML file for the website
├── css
│   └── styles.css     # Styles for the website
├── js
│   ├── main.js        # Main JavaScript functionality
│   ├── animations.js   # Animations using Anime.js and GSAP
│   └── products.js     # Product management and functionality
├── assets
│   ├── fonts          # Directory for font files
│   └── icons          # Directory for icon files
├── pages
│   ├── products.html  # Store page for products
│   ├── about.html     # About us page
│   └── contact.html   # Contact us page
├── package.json       # npm configuration file
└── README.md          # Project documentation
```

## Features

- **Interactive Design**: The website incorporates unique interactivity using Anime.js and GSAP for smooth animations and transitions.
- **Responsive Layout**: The design is responsive and adapts to various screen sizes for an optimal user experience.
- **Product Showcase**: A dedicated products page that displays cakes, cupcakes, and cookies with hover effects.
- **About Us Section**: Learn more about Vaan Bakes and our mission.
- **Contact Information**: Easily get in touch with us through the contact page.

## Setup Instructions

1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Install the required dependencies by running:
   ```
   npm install
   ```
4. Open `index.html` in your web browser to view the website.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Anime.js
- GSAP
